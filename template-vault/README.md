# Start here

This vault is wired for **Agentic OS**: Claude Code reads and writes it as its memory, and the HUD ([[Agentic OS]]) sits on top.

## Structure

- **00_Meta** — the control panel Claude reads first: [[Claude_Context]] (who you are), [[Vault_Map]] (where things go), [[Conventions]], [[Goals_and_Priorities]], [[Deadlines]].
- **01_Projects** — anything with a finish line. Notes here can carry `due:` frontmatter → they appear in the HUD's deadlines.
- **02_Areas** — ongoing responsibilities (work, school, health…).
- **03_Resources** — reference material; `Briefs/` (news) and `YouTube/` (video notes) are written by skills.
- **04_Archive** — finished or dead things. Nothing gets deleted; it moves here.
- **05_Daily** — one note per day.
- **06_Claude_Sessions** — a log whenever Claude and you do real work together.
- **07_Concepts** — the permanent layer: one idea per note, in your own words, heavily linked.
- **_Templates** — note templates (point Obsidian's Templates / Daily notes plugins here).

## The idea

Two layers. **Transient** notes (dailies, logs, raw captures) are tied to a date. **Permanent** notes in `07_Concepts` are ideas that outlive their source. `/mine` promotes the good parts from one to the other.

## First steps

1. Fill in [[Claude_Context]] — it's what makes Claude useful from the first message.
2. Put this month's priorities in [[Goals_and_Priorities]] and dates in [[Deadlines]].
3. Open [[Agentic OS]] and press **Plan Today**.
