# Deadlines

The HUD reads every table row whose first cell is a date (`YYYY-MM-DD`, optionally followed by a time). Add 🔴 to make a row critical. Notes in `01_Projects/` and `02_Areas/` with `due:` frontmatter are picked up automatically, so only list dates here that don't have their own note.

| Date | What | Tag |
|---|---|---|
| 2030-01-15 | Example: tax filing 🔴 | admin |
| 2030-02-01 09:00 | Example: application deadline | career |
